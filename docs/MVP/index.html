      STEP 3 · COMPARE 슬라이드 10 · 11 · 18
      
  
      A와 B를 나란히 놓고 보세요
      
  
      예쁜 화면보다 PRD의 흐름과 범위에 맞는지 먼저 봅니다. 빈 입력, 여러 번 누르기, 아주 긴 글도 직접 넣어 보세요.
      

  
      
    
      오늘 나의 집중 과제
      
    
      목표는 모두 같습니다. 어디에 더 집중할지만 고르세요. 중간에 바꿔도 됩니다.
      
    
      
      
      
      
      
    
      
    
      과제를 고르면 무엇을 확인할지 알려 드립니다.
      
  
      

  
      
    
      
      화면 크기
      
      
      배치
      
      
    
      
    
      
    
      휴대폰 크기는 나란히, PC 크기는 위아래로 크게 보여 줍니다. “다시 실행”은 새로고침과 같아서, 새로고침 뒤에도 글이 남는지 확인할 때 누릅니다.
      
  
      

  
      
    
      MUST 기능이 실제로 동작하나요?
      
    
      화면에 버튼이 있는 것만으로는 부족합니다. 직접 눌러서 결과까지 확인하세요.
      
    
      
  
      

  
      
    
      완성도 다섯 가지
      
    
      첫 결과가 최종 제품으로 자라려면 필요한 기준입니다.
      
    
      
  
      

  
      
    
      PRD에 없는데 생긴 기능
      
    
      요청하지 않은 기능, 나중에 만들기로 한 기능, 필요 없는 화면이 끼어들었는지 찾습니다.
      
    
      
      
      
        Version A에만 / A에서 추가된 것
        
      
        
      
        
      
      
      
      
        Version B에만 / B에서 추가된 것

      STEP 5 · JUDGE 슬라이드 13–14
      
  
      이 차이는 위반일까요, 빈칸일까요?
      
  
      PRD에서 그 내용을 찾아보세요. 기준이 있으면 위반, 없으면 빈칸입니다. 둘 다일 수도 있습니다.
      

  
      
    
      PRD 위반 → 코드를 고친다
      PRD에 분명한 기준이 있는데 AI가 지키지 않았습니다. 문제 · 근거 · 결과 · 범위로 수정 요청을 보냅니다.
      
    
      PRD의 빈칸 → 내가 결정한다
      PRD에 기준이 없어서 AI가 하나를 골랐습니다. AI 잘못이 아닙니다. 내가 정하고 PRD에 적어 보완합니다.
      
  
      
  
      
  
      
  
      

      



      
  
      STEP 6 · DECIDE 슬라이드 15–16 · 실습 ③
      
  
      섞기 전에, 기준과 이유부터 적으세요
      
  
      “둘 다 좋은 거 합쳐 줘”라고 하면 AI가 또 마음대로 고릅니다. 무엇을 유지하고 바꿀지 이유와 함께 정합니다.
      

  
      
    
      
      
      위반은 수정할 내용으로, 빈칸은 내가 내린 결정으로 넣어 줍니다.
    
      
    
      
      
      
        
      Version A에서 유지할 부분
      
        
      Version B에서 유지할 부분
      
        
      변경할 부분과 이유
      
        
      제거할 부분과 이유
      
      
      
      
      
        최종 버전에서 반드시 지킬 완료 기준
        
      PRD의 완료 기준 중에서 오늘 확인할 것을 고르세요.
      
        
      
        
      새로 정한 완료 기준 (빈칸 결정 등)
      
      
      
    
      
  
      

  
      
    
      최종본 요청문 · 자동으로 채워집니다
      
    
      
    
      새 대화라면 PRD.md · version-a.html · version-b.html을 꼭 함께 첨부하세요. 파일이 없으면 AI는 A와 B를 모릅니다.
      
  
      

  
      
    
      
      
      최종본 저장
      
      
      받은 결과를 index.html로 저장하고 열리는지 확인합니다.
      
      
      
    
      
    
      
      
      이 단계의 기록
      
      
      빈칸에서 내린 결정은 PRD에도 채워 둡니다.

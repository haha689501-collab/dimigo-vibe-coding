# 익명게시판

## 1. 프로젝트 개요

사람들이 익명으로 자신의 생각을 올리는 웹앱

- 카테고리: 커뮤니티

## 2. 해결하려는 문제

실제로는 하지 못하는 말이 많기 때문에 익명이라는 공간에서 하고 싶은 말을 하고 싶을 때가 있다. 하지만 익명이라는 그늘 때문에 서로에게 실례가 되는 행동을 하는 일이 많다. 예로 익명에서 한 사람을 여럿이서 비난하는 일이라든지 혹은 확인되지 않은 사실을 사실인척 속여서 혼란을 야기하든지 등 말이다.

## 3. 주요 사용자

- 사용자: 고등학교 학생
- 사용 상황: 자신의 생각을 공유하고 싶을 때
- 사용 기기: 노트북,컴퓨터

## 4. User Flow

1. 사이트에 접속한다
2. 계정을 등록/로그인한다
3. 게시판에 들어가서 글들을 확인한다
4. 게시판에 자신의 의견을 자유롭게 적는다
5. 다른 사람의 글에 자신의 의견을 남긴다
6. 3~5번을 반복

## 5. MVP

### 이번에 만들 기능

- 자신의 글 등록
- 타 사용자의 글 읽기
- 타 사용자의 글에 댓글 달기
- 사용자들의 내용 확인 후 ai가 관리자에게 문제가 될 수 있는 부분을 보냄
- 글에 카테고리를 추가하여 특정 카테고리만 보이게 하는 기능

### 나중에 만들 기능

- 타 사용자의 글에 좋아요 혹은 싫어요 달기
- 댓글 알림기능
- 자유 채팅방
- 글에 이미지/동영상 첨부 기능 구현
- 관리자는 글을 삭제, 사용자를 정지/추방할 권한

## 6. UI 구성

- 제목
- 목록
- 검색
- 필터

- 가장 먼저 보여야 하는 것: 해당 게시판의 이름
- 가장 중요한 버튼: 글 등록하기
- 추가 메모: 가장 위에 게시판의 이름이 적혀 있고 화면 세로 3/4정도로 게시글들이 보임, 이때 좋아요를 많이 받은 글들은 3개 정도가 골라져서 위에 보임 게시글들 위에 오른쪽에는 검색 가능한 창이 있고 왼쪽에는 필터로 검색이 있음. 게시글에 들어가면 아랫쪽에 좋아요/싫어요를 할 수 있게하고 그 아래 댓글 달기가 있음. 화면에서 자유채팅 창으로 이동가능한 버튼이 있고 자유 채팅 창에서도 게시글 창으로 이동가능한 버튼이 있음.

## 7. Acceptance Criteria

- 글을 등록할 수 있다.
- 등록된 글이 타사용자에게도 보인다
- 타사용자의 글에 달린 댓글을 볼 수 있고 자신의 글에 달린 댓글도 볼 수 있다.
- ai가 부적절한 글이나 댓글을 방장에게 알림
- 적은 글이 유지됨
- 등록된 글을 본인이 수정가능
- 자유채팅창에 올리는 말들을 확인가능
- 글에 댓글을 달 수 있음
- 글에 좋아요/싫어요를 달 수 있음

## 8. 수정 기록

- 익명성의 정의를 게시글 및 댓글 작성자의 실제 계정 정보는 다른 사용자에게 공개되지 않으며, 게시판에서는 익명 닉네임으로 표시된다. 관리자는 필요한 경우 문제 게시물의 작성자를 확인할 수 있다. 로 바꾸었다
- 신고 기능을 추가하였다
- AI 기능을 구체화 하였다
- 게시글의 기본 정보도 Acceptance Criteria에 넣었다
- 댓글도 수정/삭제 여부를 추가했다
- 카테고리 예시도 미리 정하였다
- 검색 조건을 명확히 하였다
- 자유채팅을 MVP에서 뺏다

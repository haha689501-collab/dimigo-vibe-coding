# 익명 계시판

## 1. 프로젝트 개요

서로의 의견을 공유하되, 정보를 제한하여 상대를 현실에서 특정하기 힘들도록 함으로 표현의 자유를 마음껏 뽐낼 수 있는 계시판

- 카테고리: 커뮤니티

## 2. 해결하려는 문제

현실에 존재하는 익명 계시판은 이미 많으나, 그것들이 가지는 문제가 있다. 예를 들면 익명성으로 인해 발생하는 사이버 불링, 표현의 자유를 가장한 고인 모독 및 혐오 발언의 남발, 그리고 각각의 계시판이 가지는 성향 차이로 인한 갈등이 존재한다. 이는 일반 사람들이 보기에는 굉장히 좋지 못한 요소이며, 때문에 계시판 이용자들은 때때로 단순히 정보 탐색을 위해 계시한을 이용함에도 비난을 받기도 한다.

## 3. 주요 사용자

- 사용자: 10대 중후반 이상의 남녀노소의 사용자
- 사용 상황: 자신이 궁금해하고 원하는 정보를 찾고자 함
- 사용 기기: 스마트폰/노트북/PC

## 4. User Flow

1. 앱을 연다
2. 자신이 궁금해 하는 게시판을 검색한다.
3. 나온 게시판을 클릭한다.
4. 해당 게시판 내 글 검색창에 궁금했던 키워드를 검색한다
5. 나온 글들을 확인한다.
6. 최종적으로 나온 글을 눌러 정보를 확인한다.

## 5. MVP

### 이번에 만들 기능

- 글 작성 및 수정 및 삭제
- 게시판 검색
- 글 검색
- 관리자의 유저 차단 및 관리
- 금지어 기능(포함되있는 글 작성 불가)

### 나중에 만들 기능

- 댓글 작성 기능
- 글에 추천 및 비추천 기능
- 게시판 생성 및 삭제 및 수정
- 글 스크랩 기능
- 이모티콘 등 일반적인 텍스트 이외의 의사 표현 수단 추가 기능
- 유저 개인적인 차단 기능
- 글 정렬
- 알림 기능
- 게시판 내 카테고리 분류 기능
- 자주 사용하는 게시판 즐겨찾기 기능
- 유저 설정(아이디 / 프로필) 기능
- 투표를 통한 정책의 찬반 기능
- 개인 단어 차단 기능(설정한 단어가 들어가 있는 글은 확인 불가능)

## 6. UI 구성

- 제목
- 설명
- 버튼
- 목록
- 검색
- 입력창

- 가장 먼저 보여야 하는 것: 전체 게시판 목록 (인기순 또는 등록순으로 정렬)
- 가장 중요한 버튼: 게시판 검색 버튼
- 추가 메모: 상단에 검색 창을 배치, 하단에 게시판들을 나열해서 배치, 색깔은 다크와 화이트 모드를 나누며 장기간 사용에도 눈이 피로하지 않게 파스텔 톤을 사용하며 강렬한 색의 사용을 자제함

## 7. Acceptance Criteria

- 빈 값 입력 시 저장되지 않음
- 글을 작성 도중 이탈 후 재 접속 시 글을 이어서 작성 가능함
- 관리자는 신고된 글/유저를 확인하고 차단 처리할 수 있음
- 유저는 자신이 설정한 차단 유저·단어가 포함된 글/댓글을 볼 수 없음
- 금지어가 포함된 글은 작성 시 저장되지 않고 안내 메시지가 표시됨
- 게시판 검색 및 글 검색 결과가 입력 후 즉각적으로 표시됨
- 댓글 작성이 등록 후 즉각적으로 화면에 반영됨

## 8. 수정 기록

- 게시판 검색을 MVP로 이동
- 금지어를 MVP로 이동
- UI 첫 화면을 즐겨찾기에서 전체 게시판 목록으로 변경
- 모호한 표현을 정확하게 교체

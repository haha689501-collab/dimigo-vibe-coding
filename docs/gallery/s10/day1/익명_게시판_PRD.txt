# 익명 게시판

## 1. 프로젝트 개요

익명으로 올리는 게시판

- 카테고리: 학습

## 2. 해결하려는 문제

익명 게시판이 없으면 서로 생각을 나누기가 어렵고, 또 서로를 알고 있는 상태에서 생각을 나눈다면 객관적이지 못해질 수 있어 불편할 수 있다. 예를 들어 물리적으로 멀리 떨어져 있거나 환경적으로 가까이 가기 어려운 사람들끼리는 익명 게시판이 없다면 서로 생각이나 대화를 나눌 수가 없어 불편할 수 있다.

## 3. 주요 사용자

- 사용자: 고등학교 학생
- 사용 상황: 하교 후 과제를 협력해서 진행하거나 자료를 같이 조사할 때
- 사용 기기: 노트북, 스마트폰

## 4. User Flow

1. 앱을 연다
2. 게시판에 새로운 글을 작성하거나, 이미 있는 글에 댓글을 적는다
3. 댓글을 통해서 서로 토의하거나 협력한다

## 5. MVP

### 이번에 만들 기능

- 글 등록
- 파일 업로드
- 댓글 작성

### 나중에 만들 기능

- 댓글 관리
- 글 찾기
- 알림
- 반응

## 6. UI 구성

- 제목
- 목록
- 검색
- 설명

- 가장 먼저 보여야 하는 것: 작성되어 있는 글 목록
- 가장 중요한 버튼: 검색하기
- 추가 메모: 글들이 잘 보이게 제목이 도드라지는 목록 느낌이 되어야 하고, 검색 기능을 쉽게 발견할 수 있도록 글의 목록 위에 존재해야 한다 / 또 댓글 입력 버튼은 글을 누르면 쉽게 발견할 수 있게, 글 바로 아래에 존재해야 한다

## 7. Acceptance Criteria

- 글의 제목이 비어있으면 안 된다
- 댓글의 순서와 내용이 저장되어야 한다
- 글을 삭제하고 추가할 수 있어야 한다
- 글을 검색할 수 있어야 하고, 제목 전체가 아니더라도 검색이 되어야 한다
- 디바이스에 맞추어 UI가 달라져야 한다

## 8. 수정 기록

- 댓글 관리 기능과 삭제 권한을 구분하는 것을 MVP에 추가하였다
- 기기에 따라서 UI가 달라지는 것을 명확하게 했다
- 검색 기능이 제목만인지, 본문도 포함인지를 명확히 했다
- 신고 기능을 MVP에 추가했다
- 파일 업로드 기능에 제약을 추가했다

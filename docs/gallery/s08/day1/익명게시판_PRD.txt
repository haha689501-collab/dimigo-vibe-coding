# 익명게시판

## 1. 프로젝트 개요

학교 구성원이 자신의 신원을 공개하지 않고 학교에 대한 의견과 정보를 자유롭게 공유할 수 있는 익명 커뮤니티

- 카테고리: 게임

## 2. 해결하려는 문제

실명 노출과 주변의 시선 및 보복에 대한 우려로 학생들이 학교폭력이나 부조리와 같은 민감한 문제를 자유롭게 이야기하기 어렵다. 또한 학교생활에 대한 정보와 개인적인 고민을 안전하게 공유할 수 있는 공간이 부족하다. 따라서 학생들이 신원을 공개하지 않고 학교에 대한 의견과 정보를 자유롭게 공유할 수 있는 익명 커뮤니티를 제공하고자 한다.

## 3. 주요 사용자

- 사용자: 학교 이메일 인증이 가능한 고등학교 학생
- 사용 상황: 학교에 대한 의견을 말하고 싶을 때
- 사용 기기: 컴퓨터

## 4. User Flow

1. 학교 이메일을 통해 재학생 인증을 완료한다.
2. 인증이 완료되면 익명 계정을 생성한다.
3. 최신 게시글과 실시간 투표를 확인한다.
4. 글쓰기 버튼을 눌러 일반·고발·투표 중 게시글 유형을 선택한다.
5. 게시글을 작성하여 등록하고 다른 사용자의 게시글에 공감하거나 댓글을 작성한다.
6. 투표 게시글에 참여하고 투표 결과를 확인한다.
7. 규칙을 위반한 게시글이나 댓글을 발견하면 신고한다.
8. 필요한 경우 자신의 계정 및 개인정보 삭제를 요청한다.

## 5. MVP

### 이번에 만들 기능

- 학교 이메일 단방향 암호화 인증
- 게시글 및 댓글 게시/수정/삭제
- 투표 기능(등록, 결과 시각화 등)
- 내 활동 기록 영구 파기
- 개인정보, 작성글 데이터 분리 저장

### 나중에 만들 기능

- 키워드 검색
- 접속 IP 및 활동 로그 자동 파기
- 게시글별 랜덤 닉네임 부여
- 누적 신고 자동 블라인드
- 부적절한 게시글 신고
- 메타데이터 자동 삭제
- 실시간 인기 게시글 선정
- 카테고리별 정렬 및 필터
- 내 활동 모아보기

## 6. UI 구성

- 제목
- 목록
- 검색
- 필터
- 설명
- 기타

- 가장 먼저 보여야 하는 것: 최신 글
- 가장 중요한 버튼: 글쓰기
- 추가 메모: 기존 익명 게시판들과는 다르게 광고 최소화, 깔끔한 UI

## 7. Acceptance Criteria

- 글이나 댓글을 등록하면 작성자의 개인정보(ID, 이메일 등)가 게시글 데이터와 분리되어 암호화 저장된다
- 글과 댓글 작성 시 정상적으로 등록 및 수정 가능하다
- 투표 글이 등록되면 다른 사용자들이 실시간으로 참여할 수 있고, 투표 후 결과가 시각화되어 나타난다
- 내 활동 기록 영구 파기 시 모든 데이터가 자동으로 삭제된다
- 데이터베이스 내의 회원 정보를 사용하더라도 실제 개인을 식별할 수 없

## 8. 수정 기록

- 익명 게시판의 목적을 학교에 대한 의견과 정보를 자유롭게 공유하는 커뮤니티로 구체화했다.
- 학교 이메일 인증과 개인정보·게시글 데이터 분리를 통해 익명성 기준을 명확히 했다.
- 게시글·댓글 작성 및 수정·삭제 기능을 MVP의 핵심 기능으로 정리했다.
- 일반·고발·투표 카테고리를 추가하고 투표 결과 시각화 기능을 구체화했다.
- 계정 삭제와 접속 로그 삭제 등 개인정보 관리 기준을 구체화했다.

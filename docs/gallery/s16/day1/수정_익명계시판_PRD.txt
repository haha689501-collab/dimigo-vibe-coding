# 익명계시판

## 1. 프로젝트 개요

학생들이 자신의 이름을 공개하지 않고 고민, 질문, 정보와 의견을 자유롭게 나눌 수 있는 학교 익명 커뮤니티 웹사이트입니다.

- 카테고리: 커뮤니티

## 2. 해결하려는 문제

학생들이 학교생활 중 생기는 고민이나 의견을 솔직하게 이야기하고 싶어도 신원이 드러나거나 다른 사람의 시선을 받을까 걱정되어 자유롭게 말하지 못하는 문제를 해결합니다.

## 3. 주요 사용자

- 사용자: 고등학생
- 사용 상황: 학생이 학교생활에 관한 고민이나 질문이 있지만 주변 사람에게 직접 말하기 어려울 때, 익명으로 글을 작성하고 다른 학생들의 조언이나 의견을 확인하기 위해 사용합니다.
- 사용 기기: 전자 기기

## 4. User Flow

1. 익명게시판을 연다.
2. 게시글을 읽거나 새 글을 작성한다.
3. 익명으로 글을 등록한다.
4. 다른 글에 댓글을 작성한다.
5. 작성된 댓글을 확인한다.

## 5. MVP

### 이번에 만들 기능

- 익명 글 작성
- 댓글 작성
- 게시글 검색
- 좋아요 기능
- 부적절한 글 신고

### 나중에 만들 기능

- 게시글 목록 보기
- 게시글 삭제
- 게시글 카테고리 선택

## 6. UI 구성

- 제목
- 버튼
- 카드
- 목록
- 필터

- 가장 먼저 보여야 하는 것: 최신 익명 게시글 목록
- 가장 중요한 버튼: 익명 글쓰기
- 추가 메모: 밝고 깔끔한 디자인으로 만들고, 게시글은 카드 형태로 보여준다. 카테고리와 작성 시간도 함께 표시한다

## 7. Acceptance Criteria

- 제목과 내용을 입력하면 익명 게시글이 등록된다.
- 등록한 게시글이 목록에 나타난다.
- 게시글을 선택하면 내용과 댓글을 볼 수 있다.
- 게시글에 익명 댓글을 작성할 수 있다.
- 작성자는 자신의 게시글을 삭제할 수 있다.
- 빈 제목이나 내용은 등록되지 않는다.
- 새로고침 후에도 게시글이 유지된다.

## 8. 수정 기록

- 글쓰기 버튼을 더 잘 보이도록 수정했다.
- 검색 기능은 나중에 추가하기로 했다.
- 게시글을 카드 형태로 보이도록 수정했다.

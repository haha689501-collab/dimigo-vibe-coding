# 익명 게시판

## 1. 프로젝트 개요

자신의 관심사와 아예 다른 주제들을 추천하여 새로운 아이디어나 토픽을 떠올릴 수 있게 하는 익명 게시판. 유리병 편지를 바다에 띄우는 컨셉.

- **카테고리**: 커뮤니티

## 2. 해결하려는 문제

추천 알고리즘 때문에 필터 버블에 갇혀 자신이 좋아하는 하나의 주제에 관련한 글만 보게 되는 사람들은 편향적인 사고를 가질 수 있으며 새로운 주제를 탐색하고 싶어하기도 한다. 하지만 추천 알고리즘 때문에 그럴 수 없다.

## 3. 주요 사용자

| 항목 | 내용 |
|---|---|
| 사용자 | 새로운 아이디어를 탐색하고 싶은 사람들 |
| 사용 상황 | 새로운 아이디어를 탐색하고 싶을 때 |
| 사용 기기 | 스마트폰, 패드, 노트북 |

## 4. User Flow

1. 앱을 연다.
2. 추천되는 새로운 아이디어(유리병)를 탐색한다.
3. 마음에 드는 유리병을 저장한다. (기기 로컬 저장, 서버 미연동)
4. 자신이 쓰고싶은 글(유리병)을 작성해 바다로 던진다.

## 5. MVP

### 이번에 만들 기능

- AI 기반 글 자동 분류 (고정 카테고리 리스트)
- 연속 추천 방지 로직 (직전 노출된 N개와 같은 카테고리 제외, N=3~5)
- 글 저장 (localStorage, 서버 미연동 — 기기별 로컬 저장이라 익명성 유지)
- 새로운 글 작성
- 초기 시드 글 (콜드스타트 대응, 카테고리별 최소 수량 확보)

### 나중에 만들 기능

- 글 신고
- 특정 주제 차단
- 최소 금칙어 필터
- 배 타고 바다 돌아다니며 유리병 찾는 게임형 인터랙션

## 6. UI 구성

- **컴포넌트**: 버튼, 카드
- **가장 먼저 보여야 하는 것**: 새로운 유리병(글) 추천
- **가장 중요한 버튼**: 새로운 글 작성(유리병 던지기) 버튼
- **추가 메모**: 메모장 같은 UI. "새로고침" 대신 "다음 유리병 건지기" 같은 컨셉 카피 사용

## 7. Acceptance Criteria

- [ ] 비슷한 카테고리의 글이 연속적으로 추천되지 않는다.
- [ ] 내가 작성한 글이 등록된다. (작성자 식별 없음)
- [ ] 글을 로컬 기기에 저장할 수 있다. (앱 재설치/기기 변경 시 소실 가능)
- [ ] 빈 글은 등록되지 않는다.
- [ ] 새로고침 시 추천글 목록이 랜덤하게 바뀐다.
- [ ] 한 세션 내 최소 2개 이상 다른 카테고리의 글을 접한다.

# 익명 게시판

## 1. 프로젝트 개요

사용자가 매 시간마다 새롭게 공개되는 주제에 대해 찬성 혹은 반대 입장을 선택하고 익명으로 실시간으로 토론할 수 있게하는 서비스

- 카테고리: 커뮤니티

## 2. 해결하려는 문제

기존의 커뮤니티들은 주제가 여러가지로 분산돼 하나의 주제로 많은 사람이 같이 토론하기가 어렵다. 또한, 재미없는 주제가 오래 유지돼서 참여자가 빠르게 이탈하곤 한다.

## 3. 주요 사용자

- 사용자: 짧은 시간 안에 다양한 주제에 대해서 의견을 나누고 싶은 1020

- 사용 상황: 심심

- 사용 기기: 데스크탑/휴대폰

## 4. User Flow

1. 웹앱 접속

2. 입장 선택(찬/반)

3. 토론 참여

4. 핵심 의견 확인

5. 의견 반응

6. 입장 변경

7. 주제 넘기기

8. 토론 종료

## 5. MVP

### 이번에 만들 기능

- 입장 선택

- 실시간 채팅

- 실시간 찬반 비율(현재 찬성/반대 비율 표시)

- 논점 그래프 시각화(노드 색깔:   노랑: 주요 논제, 초록: 찬성의견, 빨강: 반대의견)

- 토론 종료 및 기록

### 나중에 만들 기능

- 주제 자동 변경(1시간마다 주제 자동 변경)

- 주제 넘기기(주제 넘기기를 누른 사람이 과반수를 넘으면 새로운 주제로 변경)

- 주요 의견 자동 추출

- 의견 그룹화(비슷한 의견들을 하나의 논점으로 묶기)

- 노드 중요도 표현(공감, 언급량, 관련 의견 수에 따라서 노드 크기 변경)

## 6. UI 구성

- 입력창

- 버튼

- 가장 먼저 보여야 하는 것: 현재토론주제, 남은시간, 현재찬반비율, 찬성반대 버튼 선택, 논점 그래프, 실시간 채팅

- 가장 중요한 버튼: 찬성/반대 선택버튼

- 추가 메모: 주제 넘기기 버튼: 메인 CTA보다는 약하게. 현재 동의율 % 같이 표시. /  / 남은 시간: 상단 고정 또는 주제 바로 위에 표시. /  / 찬반 비율 바: 숫자만 말고 한눈에 비교되는 막대 형태. /  / 논점 그래프: 화면 중앙 핵심 영역. 노드 클릭 시 상세 의견 패널 표시. /  / 채팅 입력창: 하단 고정. 입장 선택 전에는 입력 비활성화. /  / 현재 참여자 수: 작게 표시해서 실시간성 강조. /  / 의견 변화 표시: 찬성 +6%처럼 토론 시작 대비 변화량 표시. /  / 그래프/채팅 전환: 모바일에서는 논점 / 채팅 탭으로 분리하는 것도 좋음. /  / 신고 버튼: 각 메시지의 보조 메뉴 안에 배치. /  / 새 주제 전환 알림: 주제가 바뀌기 직전 짧은 카운트다운 표시.

## 7. Acceptance Criteria

- 사용자는 현재 진행 중인 토론 주제와 남은 시간을 확인할 수 있다.

- 사용자는 찬성 또는 반대를 선택하고 익명으로 실시간 채팅에 참여할 수 있다.

- 1시간이 지나면 현재 토론이 종료되고 새로운 주제와 채팅방이 자동으로 생성된다.

- 참여자의 과반수가 주제 넘기기에 동의하면 1시간 전이라도 새로운 주제로 변경된다.

- 현재 찬성·반대 비율이 실시간으로 갱신된다.

- 주요 논제와 의견이 노드 그래프로 표시되며, 논제는 노랑·찬성은 초록·반대는 빨강으로 구분된다.

- 많이 언급되거나 공감을 받은 의견은 더 중요한 노드로 시각적으로 강조된다.

- 사용자가 의견 노드를 선택하면 해당 의견의 내용과 관련된 주요 메시지를 확인할 수 있다.

## 8. 수정 기록

- MVP에 포함되지 않은 주제 자동 변경, 주제 넘기기, 주요 의견 자동 추출 관련 항목을 Acceptance Criteria에서 제외했다.

- MVP 단계에서는 논점 그래프의 의견 데이터를 미리 준비하거나 수동으로 등록하고, 자동 의견 추출 기능은 이후 버전으로 이동했다.

- MVP의 토론 종료 방식은 자동 전환 대신 수동 종료 중심으로 단순화했다.

- 주요 사용자를 ‘1020’에서 ‘짧고 즉각적인 온라인 토론을 선호하는 10대 후반~20대 사용자’로 구체화했다.

# 익명 게시판

## 1. 프로젝트 개요

교내 건의사항 및 친목을 익명으로 나눌 수 있는 온라인 게시판

- 카테고리: 커뮤니티

## 2. 해결하려는 문제

새로 친해지고 싶은 친구가 있어도 학과가 달라서 다가가기 어려운 상황이 있고 또한 학생자치회에 소속되어있지 않으면 학교 정책 및 시설상 문제 등을 건의하기 어려운 상황이 발생한다.

## 3. 주요 사용자

- 사용자: 고등학교 1학년 학생
- 사용 상황: 학교 내 친목을 원하거나 건의사항이 있는 상황
- 사용 기기: 스마트폰

## 4. User Flow

1. 앱을 켠다
2. 커뮤니티 글 등록 혹은 교내 친구에게 개인문자
3. 커뮤니티 글 반응 확인 및 소통지속

## 5. MVP

### 이번에 만들 기능

- 커뮤니티 글 등록 및 삭제
- 개인 메세지 전송

### 나중에 만들 기능

- 등록된 글 댓글 등의 반응
- 교내 친구 탐색
- 커뮤니티 글 및 개인 메세지 관리

## 6. UI 구성

- 제목
- 설명

- 가장 먼저 보여야 하는 것: 등록된 커뮤니티 게시글
- 가장 중요한 버튼: 커뮤니티 글 등록
- 추가 메모: 대화 창 및 커뮤니티 글 창 전환 가능한 부분 필요

## 7. Acceptance Criteria

- 커뮤니티 글 게시 및 공유가 가능하다.
- 커뮤니티 글 삭제 및 블라인드가 가능하다.
- 교내 친구를 목록에서 찾을 수 있다.
- 친구에게 메세지를 보내고 소통이 가능하다.
- 커뮤니티 글 열람 및 댓글, 공감 등의 반응이 가능하다.

## 8. 수정 기록

- 로그인기능 추가
- 블라인드 기능 추가

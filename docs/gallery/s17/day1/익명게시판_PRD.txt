# 익명게시판

## 1. 프로젝트 개요

디미고 민원 게시판

- 카테고리: 커뮤니티

## 2. 해결하려는 문제

시설이나 시스템 등 불편한 점이 있어도 마땅한 말 할 곳이 없음

## 3. 주요 사용자

- 사용자: 디미고 학생들
- 사용 상황: 학교 내에서 불편한 상황이 생겼을 때
- 사용 기기: 스마트폰

## 4. User Flow

1. 앱을 연다
2. 로그인 한다.
3. 제목과 내용으로 이루어진 하나의 글을 쓴다.
4. 또는 다른 학생들이 작성한 글을 보며 공감 버튼을 누른다
5. 선생님들과 학생회는 학생들이 많이 공감한 글을 확인하고 개편 방안을 생각해본다.
6. 개선되었거나 기각된 의견은 게시글에 개선 또는 기각이라 적힌다.

## 5. MVP

### 이번에 만들 기능

- 글 작성 및 게시
- 게시판 확인
- 로그인
- 게시글 공감 기능

### 나중에 만들 기능

- (선생님들과 학생회의 계정에서만) 게시글 개선 및 기각 표시
- 브라우저 저장

## 6. UI 구성

- 제목
- 카드

- 가장 먼저 보여야 하는 것: 학생들의 게시글
- 가장 중요한 버튼: 글 쓰기
- 추가 메모: 오른쪽 아래에 작은 동그라미로 글 쓰기가 있고, 블로그 처럼 학생들의 게시글이 보인다.

## 7. Acceptance Criteria

- 로그인할 수 있다.
- 첫 화면에서 다른 학생들의 민원 게시판이 보인다.
- 글 게시를 하면 다른 계정에서 보인다.
- 글 게시를 하지 않았다면 나에게만 보인다.
- 선생님들과 학생회 계정에선 게시글에 개선 또는 기각 표시를 할 수 있다.
- 빈 글은 게시되지 않는다.
- 글은 저장이 되어 나갔다 들어와도 이어서 작성할 수 있어야 한다.
- 게시글엔 작성자가 누구인지 보여선 안된다.(익명 보장)
- 공감 수와 민원에 관한 글인 이유로 글은 수정할 수 없다.
- 글 삭제는 가능하다

## 8. 수정 기록

- 로그인과 익명이 충돌하여 로그인해서 글을 작성해도 자신의 글 확인이나 선생님 및 학생회 계정 확인 용도로만 사용하고 게시판에선 작성자가 완전 안보이도록 했다.
- mvp에 공감 기능을 넣었다.

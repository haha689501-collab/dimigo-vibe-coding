# 익명 게시판

## 1. 프로젝트 개요

교내 모든 학생들이 사용할 수 있는 익명 게시판

- 카테고리: 생활

## 2. 해결하려는 문제

신입생 등의 학교에 적응이 잘 안된 사람, 혹은 낯을 가리는 사람들은 교내에서 궁금한 점이나 어려운 점 들을 해결할 때 조언을 구할만한 방법이 마땅치 않음.

## 3. 주요 사용자

- 사용자: 전교생
- 사용 상황: 교내가 떠들썩한데 뭔 일이 일어났는지 모를 때
- 사용 기기: 스마트폰

## 4. User Flow

1. 앱을 연다
2. 로그인을 한다
3. 원하는 카테고리에 들어간다
4. 글쓰기 버튼을 눌러서 글을 쓴다 (제목, 내용+첨부된 사진,동영상,링크)
5. 글쓰기 완료를 눌러 글을 올린다
6. 글을 읽고 싶다면 카테고리 내에서 원하는 글을 눌러 들어간다
7. 좋아요/싫어요 버튼이 있어 누를 수 있다. (두 버튼 중복 가능, 한 버튼은 한번만 누르고 다시 누르면 취소)
8. 댓글 작성란에 댓글을 작성 후 작성하기 버튼을 눌러서 댓글을 작성한다.

## 5. MVP

### 이번에 만들 기능

- 카테고리 탭 만들기 (전체/잡담/공부/IT)
- 글 작성,수정,삭제
- 글 보기 (좋아요, 싫어요)
- 댓글 작성,수정,삭제
- 글 검색

### 나중에 만들 기능

- 회원가입
- 로그인/로그아웃

## 6. UI 구성

- 목록
- 버튼
- 검색

- 가장 먼저 보여야 하는 것: 작성된 글들이 최신순으로 나열되어 있는 전체 탭 (글들이 제목, 작성일, 작성자 형태로 리스트 형식으로 구성되어 되어있음)
- 가장 중요한 버튼: 글쓰기 버튼
- 추가 메모: 전체적으로밝은 톤에다가 버튼이나 강조 색상은 연한 남색, 왼쪽 위에는 누르면 전체 탭으로 이동하는 Memo라고 적힌 로고가 있음, 오른쪽 위에는 사용자 프로필 버튼이 있고 누르면 설정과 로그아웃 버튼이 보임(설정이랑 로그아웃은 버튼만 만들고 구현은 나중에 구현하기), 로고랑 프로필 아래에는 전체/공부/IT 라는 카테고리가 있는 탭이 있고 탭을 누르면 해당 탭의 글 리스트로 이동함(처음에는 전체 탭만 만들고 다른 탭들 상호작용은 나중에 구현하기), 글쓰기 버튼은 오른쪽 아래에 있고 전체적으로 강조 색상으로 칠해져 있음

## 7. Acceptance Criteria

- 접속 시 '전체'탭으로 이동하여 모든 글들이 리스트로 보인다
- 왼쪽 위에는 로고가 있고 오른쪽엔 프로필이 있다. 그 아래로는 카테고리 탭과 글들
- 글쓰기 버튼을 누르면 글쓰기 화면으로 이동한다
- 글쓰기 화면에선 제목, 내용을 입력받고 내용에는 사진, 동영상, 링크를 첨부할 수 있다.
- 글쓰기 완료를 누르면 글이 리스트에 추가된다, 이때 최신순 나열을 하여 최근에 쓴 글이 가장 위로 오게 한다.
- 리스트에서 각 항목은 제목, 작성일, 작성자가 적혀 있고 해당 항목을 누를 시 해당 글로 이동하여 읽을 수 있음
- 저장된 글들은 글쓴이가 삭제를 하지 않는 한 사라지면 안됨. 새로고침, 서버 재시작 등의 이밴트가 발생하여도 저장된 내용이 유지되어야 한다.

## 8. 수정 기록

- 회원가입,로그인 기능을 나중으로 밀기로
- 카테고리 목록 불일치, 최종 희망 카테고리는 (전체, 잡담, 공부, IT)임
- 익명 게시판인데 작성자 표시를 요구함, 작성자는 사용자가 임의로 정한 자신의 닉네임이며 익명성이 보장됨
- 글쓰기에서의 첨부파일 규격 제한이 없음 (최대 200MB)
- 작성일 표시 형식은 ~전으로 표시 (예:3시간전, 7일전, 3개월전)

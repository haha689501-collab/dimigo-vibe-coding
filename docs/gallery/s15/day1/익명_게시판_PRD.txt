# 익명 게시판

## 1. 프로젝트 개요

고등학생들이 익명으로 글을 올리고 공유하는 게시판.

- 카테고리: 커뮤니티

## 2. 해결하려는 문제

대학생들이 모여있는 게시판, '에브리 타임'(이하 '에타')은 존재하나, 고등학생을 위한 서비스는 존재하지 않는다.
왜냐하면, 이는 실질적으로 인터넷 절차 상 스스로 고등학생임을 증명하기 어려울 뿐더러, 사이트의 신뢰성이나 익명성 등의 부가 요소에서도 기인한다.
그러니 '고등학생만' 모여서 글을 쓰고 댓글을 남기며 소통할 수 있는 커뮤니티는 부재한 것이다.
만약 그런 사이트가 있다면, 고등학생들은 각자의 카테고리를 나누어 '입시'에 대한 정보를 공유하거나, 소소한 이야기를 공유하고, 때때로 익명이기에 더욱 진솔한 고민 상담을 하는 등 익명 게시판을 통해 고등학생들만의 커뮤니티를 구축할 수 있을 것이다.
그곳에서, 고등학생들은 부모님, 친구에게 털어놓을 수 없는 이야기나, 주변에서 듣지 못할 이야기들을 경험할 수 있다.

## 3. 주요 사용자

- 사용자: 모든 고등학생
- 사용 상황: 또래의 의견을 묻고 싶지만, 주변에 물을 사람이 없을 때
- 사용 기기: 노트북

## 4. User Flow

1. 앱을 연다.
2. 앱에서 원하는 게시판(입시, 잡담, 고민 등)을 선택하여 글을 작성하거나 읽는다.
3. 글을 작성하거나 읽은 뒤 댓글을 남기거나, 추천, 비추천 등을 남긴다.
4. 위 과정을 통해 또래 고등학생과 소통하며, 이야기를 나눈다.

## 5. MVP

### 이번에 만들 기능

- 게시판 내 글 열람 버튼
- 글 작성 (제목, 본문, 닉네임 공개 여부, 닉네임을 공개하지 않을 시 '익명'으로 표시되며, 작성한 글에 표시되지 않음)
- 게시판(입시, 잡담, 고민, 연애) 선택
- 댓글 작성
- 글 검색 (전 범위 검색, 게시판 카테고리 내 검색)

### 나중에 만들 기능

- 원하는 게시판(카테고리) 추가
- 프로필 등록(프로필 사진, 자기소개, 닉네임, 학교 공개 여부 선택)
- 작성된 글, 댓글에 대한 추천, 비추천
- 게시판 내 글 정렬 기준 버튼(최신순, 오래된 순, 추천순, 비추천순, 특정 학교 작성)
- 로그인(학교 인증 및 아이디, 비밀번호 설정)
- 작성한 글 보기(유저의 프로필 클릭 시, 닉네임 공개로 작성한 글이 보임)
- 자신의 글 보기(댓글, 글 두 개의 탭으로 나누어, 자신이 작성한 글(익명과 닉네임에 관계 없이)을 볼 수 있음)
- 자신이 작성한 글 삭제 기능

## 6. UI 구성

- 기타

- 가장 먼저 보여야 하는 것: 전체 게시판의 작성된 글 리스트
- 가장 중요한 버튼: 글 열람하기
- 추가 메모: 기본적으로 채도가 낮은 밀색(바랜 종이 색)을 바탕으로, 볼드체 제목과 그 아래에 작은 글씨로 본문 미리보기 일부가 제공된다. / UI 구성은 과한 꾸밈 없이 깔끔해야 하며, 크게 호불호를 타지 않을 수준이어야 한다.

## 7. Acceptance Criteria

- 제목이나 내용이 없는 글은 작성되지 않는다.
- 글/댓글을 정상적으로 등록할 수 있으며, 원하는 게시판과 게시물에 글과 댓글이 올라간다.
- 작성된 글/댓글이 정상적으로 다른 사용자에게 보인다.
- 검색한 내용이 올바르게 서칭된다.
- 게시판을 선택하여 해당 게시판의 글만 볼 수 있다. (선택하지 않을 시, 모든 게시판의 글이 전부 보인다. 이를 이하 전체 게시판이라 한다.)

# 익명 게시판

## 1. 프로젝트 개요

사람들이 모여서 서로 의논하고 고민상담등 온라인에서 소통하는 웹앱

- 카테고리: 커뮤니티

## 2. 해결하려는 문제

조사나 의견 수집을 할 때 주변인들만으로는 한계가 있기 때문에 다양한 사람들의 의견을 수집할 수 있는 커뮤니티를 만들어 해결할 수 있다.

## 3. 주요 사용자

- 사용자: 학생

- 사용 상황: 설문조사를 해야할때, 다양한 관점에서 문제를 바라봐야할때

- 사용 기기: 스마트폰

## 4. User Flow

1. 앱을 연다

2. 글 작성을 누른다

3. 어떤 부분인지 고르고 글을 작성한뒤 게시한다

## 5. MVP

### 이번에 만들 기능

- 글 작성

- 댓글

- 투표 기능

### 나중에 만들 기능

- 좋아요 기능

- 토론 기능

- 욕설등 고소가 가능하거나 상대방을 비방하는 단어나 표현 필터링

## 6. UI 구성

- 제목

- 검색

- 목록

- 입력창

- 가장 먼저 보여야 하는 것: 지금 가장 반응이 큰 토론/고민 주제

- 가장 중요한 버튼: 글 쓰기

- 추가 메모: -

## 7. Acceptance Criteria

- 글 작성을 하고 게시하면 성공적으로 올라간다

- 찬반 투표를해 일정시간이 지나면 결과가 나온다

- 글을 수정할 수 있다

- 좋아요를 누르면 개수가 증가한다

- 새로고침을 하면 작성한 글에 대한 반응의 변화가 보인다(좋아요, 댓글, 투표등)

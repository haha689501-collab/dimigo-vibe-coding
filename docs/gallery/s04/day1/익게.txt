# 익명 게시판

## 1. 프로젝트 개요

트위터같이 가벼운 글을 많이 쓰고, 쉽게 접근할 수 있는 익명 게시판

- 카테고리: 커뮤니티

## 2. 해결하려는 문제

사용자가 익명으로 작은 커뮤니티에서 짧게 의견을 내고 싶고, 간단히 다른 사람들과 의견을 공유하고 싶은데 다른 커뮤니티는 UI가 그에 맞지 않음.

## 3. 주요 사용자

- 사용자: 교내 학생
- 사용 상황: 심심할 때
- 사용 기기: 스마트폰

## 4. User Flow

1. 앱을 연다
2. 글을 둘러본다
3. 댓글을 쓰거나 새로운 글을 작성한다

## 5. MVP

### 이번에 만들 기능

- 글 등록/삭제/수정
- 댓글 등록/삭제/수정
- 글 좋아요/싫어요
- 글에 미디어 포함 기능

### 나중에 만들 기능

- 매번 로그인할 때 ID가 달라지는 기능
- 인물 특정성을 막기 위한 개인정보 보호 기능
- 게시물 자동 소멸
- 투표형·양자택일 게시물
- 위기 신호 감지 및 도움 안내
- 신고 누적 시 자동 블라인드

## 6. UI 구성

- 기타
- 목록
- 카드
- 버튼
- 검색

- 가장 먼저 보여야 하는 것: 글 목록
- 가장 중요한 버튼: 글 쓰기
- 추가 메모: 가독성이 좋은 글들 목록이 잘 보이는 UI였으면 좋겠고, 간단하고 미니멀했으면 좋겠다.

## 7. Acceptance Criteria

- 빈 값은 저장되지 않는다
- 쓴 글이 목록에 나타난다.
- 글쓴이가 수정할 수 있다
- 글과 댓글 삭제, 수정 작성이 잘 되어야 한다.
- 쇼츠처럼 글을 볼 수 있는 기능이 있어야 한다
- 싫어요 수는 작성자에게만 보인다

## 8. 수정 기록

- 싫어요 수는 작성자에게만 보인다는 기능 추가
- 글 삭제 주체 정의

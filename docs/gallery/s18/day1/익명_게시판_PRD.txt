# 익명 게시판

## 1. 프로젝트 개요

디미고의 분실물을 업로드하는 게시판

- 카테고리: 커뮤니티

## 2. 해결하려는 문제

기존 불실물은 습득되면 보건실에 보관되고 하이클래스에 공지가 올라오는데 접근성이 좋지 않아 공지를 놓칠 때가 많음

## 3. 주요 사용자

- 사용자: 디미고 재학생
- 사용 상황: 분실물이 발생했을 때
- 사용 기기: 스마트폰

## 4. User Flow

1. 앱을 연다
2. 자신이 습득한/분실한 분실물에 관해 글을 올린다
3. 분실물의 주인을 찾은 글을 체크하면 내려간다

## 5. MVP

### 이번에 만들 기능

- 분실문 등록
- 분실물 재습득 확인

### 나중에 만들 기능

- 분실물 습득/분실 장소별 분류
- 분실물의 종류별 분류
- 게시글 최신순 정렬
- 분실물 검색
- 분실물을 찾아준 사람에 대한 보상 시스템

## 6. UI 구성

- 목록
- 검색
- 버튼

- 가장 먼저 보여야 하는 것: 현재 등록된 분실물 목록
- 가장 중요한 버튼: 게시글 등록하기
- 추가 메모: -

## 7. Acceptance Criteria

- 게시글을 올릴때 내용이 없으면 업로드가 취소된다
- 분실물은 최근에 업로드되 순으로 정렬된다
- 분실물을 체크하면 삭제된다
- 새로고침 후에도 업로드한 게시물이 유지된다
- 게시글이 업로드되면 즉각 화면에 표시된다

## 8. 수정 기록

- 습득글/분실글 구분
- 사진 추가 가능

# 익명게시판

## 1. 프로젝트 개요

익명으로 글을 올리고 소통하는 게시판

- 카테고리: 커뮤니티

## 2. 해결하려는 문제

평소 학교생활에서 불편한 점 제의나 수행평가 글 공유 등 일상생활의 문제를 해결한다.

## 3. 주요 사용자

- 사용자: 우리반 학생

- 사용 상황: 학교에서.

- 사용 기기: 스마트폰과 PC

## 4. User Flow

1. 앱을 연다

2. 우측 하단 모서리의 + 모양의 게시글 올리기 버튼을 누른다

3. 제목란에 제목을 적고 사진/파일등을 끌어오기 해서 원할 시에 첨부한뒤, 글을 작성하고 게시글 작성카드의 우측 상단 모서리의 게시하기 버튼을 누른다

4. 게시글을 게시하시겠습니까? 라는 문구가 뜨고, 게시를 원할 시에 게시하기를 한번 더. 아니면 수정 및 삭제 버튼을 누른다

## 5. MVP

### 이번에 만들 기능

- 우리반 학생들 모두가 접속 가능한 전역 서버기능

- 게시글 작성할때 파일첨부기능

- 게시글 저장 등 데이터 저장 DB

- 게시글 작성 및 삭제(자신의 글만 삭제가능)

- 가상 스크롤링

### 나중에 만들 기능

- 게시글 댓글기능

- 게시글의 댓글의 대댓글 기능

- 좋아요/싫어요 기능

- 게시글 검색기능

- 관리자 기능과 권한보안

## 6. UI 구성

- 목록

- 검색

- 기타

- 가장 먼저 보여야 하는 것: 게시글들

- 가장 중요한 버튼: 게시하기 버튼

- 추가 메모: 인스타같은 UI

## 7. Acceptance Criteria

- 전역 서버가 작동하여 어디서나 인터넷만 연결되면 접속가능함

- 게시글이 올라감

- 게시글 정보가 DB에 저장되어 새로고침해도 진행사항이 없어지지 않음

- 게시글이 작성가능함

- 가상 스크롤 기능이 잘 작동함.

- 게시글 검색기능이 일치도 점수 기반으로 작동함

- 관리자 기능이 작동하여 권한이 보안상태가 우수하고 권한설계목적대로 작동함

## 8. 수정 기록

- 검색기능을 필수로 넣었다

- 관리자 기능을 추가했다

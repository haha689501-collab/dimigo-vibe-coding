# 익명게시판

## 1. 프로젝트 개요

익명으로 활동할 수 있는 게시판

- 카테고리: 커뮤니티

## 2. 해결하려는 문제

개인정보가 노출될 위험을 걱정하지 않고 맘 편히 사람들과 소통할 수 있다.

## 3. 주요 사용자

- 사용자: 익명으로 소통하고 싶은 남녀노소의 사용자
- 사용 상황: 게시판을 익명으로 사용하고 싶을 때
- 사용 기기: 스마트폰, 노트북, 태블릿, 컴퓨터 등등

## 4. User Flow

1. 앱을 연다
2. 다른 사람의 글을 본다.
3. 댓글이나 대댓글을 작성하거나 글을 작성한다.
4. 바꿀 내용이 있다면 글을 수정한다.
5. 삭제하고 싶다면 글을 삭제한다.

## 5. MVP

### 이번에 만들 기능

- 글 작성
- 글 수정
- 글 삭제
- 글 서버에 저장(db)
- 글 조회

### 나중에 만들 기능

- 사용자 정보 서버에 저장(db)

## 6. UI 구성

- 제목
- 버튼
- 목록
- 검색
- 필터

- 가장 먼저 보여야 하는 것: 글 목록(제목, 닉네임, 날짜 등)
- 가장 중요한 버튼: 글 작성하기
- 추가 메모: 메인 색상은 파란색. 심플 이즈 베스트. 둥근 ui는 ai같아서 각진 스타일이 좋음

## 7. Acceptance Criteria

- 다른 사람의 글은 수정, 삭제할 수 없다
- 글 작성이 되며 다른 사람의 글 목록에서도 잘 반영이 된다.
- 사용자 계정이 db에 잘 저장된다.
- 글 수정이 되며 다른 사람의 글 목록에서도 잘 반영이 된다.
- 작성하던 글을 중간에 나가도 나중에 이어서 쓸 수 있다.

## 8. 수정 기록

- 사용자 정보 저장은 mvp에서 제외했다.
- 로그인 기능을 mvp에서 제외했다.

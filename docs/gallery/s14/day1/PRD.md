# 익명 게시판

## 1. 프로젝트 개요

로그인은 하되 글에는 이름이 남지 않는, 누구나 참여할 수 있는 공개 익명 커뮤니티

- 카테고리: 커뮤니티

## 2. 해결하려는 문제

익명성을 높이면 솔직해지지만 책임이 사라지고, 책임을 물으려 실명을 요구하면 아무도 말하지 않는다.

### 해결 방식

화면에는 작성자를 전혀 노출하지 않되, 서버에는 계정 식별자를 해시한 값만 저장한다.
이용자는 익명으로 말할 수 있고, 운영자는 신고가 누적된 계정에 제재를 가할 수 있다.
단, 이는 완전한 익명이 아니라 '운영자에게만 열린 익명'이므로, 서비스 안내 문구에서 절대 익명처럼 표현하지 않는다.

## 3. 주요 사용자

- 사용자: 이름이 드러나는 것이 부담스러워 말을 꺼내지 못하는, 10~30대 온라인 커뮤니티 이용자
- 사용 상황: 실명으로는 꺼내기 어려운 이야기를, 주로 심야·이동 중에 짧게 쓰고 반응을 확인하는 상황
- 사용 기기: 스마트폰 중심의 모바일 웹, 데스크톱 브라우저 병행 지원 (반응형)

## 4. User Flow

1. 웹사이트에 접속해 로그인한다.
2. 게시글 목록에서 최근 글을 확인한다.
3. 읽고 싶은 글을 눌러 본문과 댓글을 확인한다.
4. 글쓰기 버튼을 눌러 익명으로 글을 작성한다.
5. 작성한 글에 달린 댓글과 반응을 확인한다.
6. 필요하면 '내가 쓴 글'에서 글을 삭제한다.

## 5. MVP

### 이번에 만들 기능

- 회원가입 및 로그인
- 익명 글 작성
- 댓글 작성
- 내가 쓴 글 확인 및 삭제
- 게시글 신고

### 나중에 만들 기능

- 게시판 카테고리 분류
- 관리자 숨김 처리

## 6. UI 구성

- 제목
- 목록
- 카드
- 버튼

- 가장 먼저 보여야 하는 것: 최신순으로 정렬된 익명 게시글 목록
- 가장 중요한 버튼: 글쓰기
- 추가 메모: 모바일 화면을 기준으로 설계하고, 데스크톱은 가운데 정렬로 폭만 제한한다. / 첫 화면은 상단 제목, 그 아래 게시글 카드 목록, 우측 하단에 고정된 글쓰기 버튼으로 구성한다. / 각 카드에는 글 제목, 본문 첫 두 줄, 작성 시각, 댓글 수, 회색 '익명' 라벨만 표시하고 작성자 정보는 어디에도 노출하지 않는다. / 밤에 쓰는 이용자가 많을 것으로 보아 다크 단일 테마로 구성하고, 강조색은 글쓰기 버튼 한 곳에만 사용한다. / 빈 화면일 때는 "아직 글이 없습니다. 첫 글을 남겨보세요."를 안내한다.

## 7. Acceptance Criteria

- 로그인하지 않으면 글쓰기와 댓글 작성이 차단된다.
- 작성한 글이 목록 맨 위에 나타난다.
- 게시글과 댓글 어디에도 작성자의 아이디나 이름이 표시되지 않는다.
- 내가 쓴 글 목록에서 본인 글만 확인하고 삭제할 수 있다.
- 다른 사용자의 글 번호로 삭제를 요청해도 처리되지 않는다.
- 댓글을 작성하면 해당 글의 댓글 수가 1 증가한다.
- 제목이나 본문이 비어 있으면 글이 저장되지 않는다.
- 신고가 3회 누적되면 해당 글이 목록에서 자동으로 숨겨진다.
- 새로고침하거나 다시 접속해도 작성한 글과 댓글이 그대로 남아 있다.

## 8. 기술 및 운영 조건

- 기술 스택: Express + SQLite, 서버 렌더링 또는 REST API 방식
- 개인정보: IP는 해시 후 저장하고 보관 기간 경과 시 파기, 게시물 테이블에 계정 원본 식별자를 저장하지 않음
- 도배 방지: 계정 단위 작성 간격 제한
- 비밀번호 저장: bcrypt 등 단방향 해시 사용

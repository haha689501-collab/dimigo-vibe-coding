# 익명게시판

## 1. 프로젝트 개요

맘 편히 떠들 수 있는 게시판

- 카테고리: 커뮤니티

## 2. 해결하려는 문제

실명이 언급되거나 인물이 특정되어 비난을 받는 것이 두려운 사람들이 마음 편히 웃고 떠들 수 있는 게시판을 만드는 것

## 3. 주요 사용자

- 사용자: 초등학생, 중학생, 고등학생
- 사용 상황: 집에서 쉬는 상황
- 사용 기기: 스마트폰, 컴퓨터를 포함한 전자기기들

## 4. User Flow

1. 앱을 연다.
2. 원하는 카테고리에 입장한다.
3. 글을 작성하거나 채팅방에 입장한다.
4. 익명으로 떠들며 웃는다.
5. 문제가 생긴다면 신고한다.
6. 신고가 접수되면 관리자가 적절한 조치를 취한다.

## 5. MVP

### 이번에 만들 기능

- 카테고리 분류 및 생성, 제거, 수정
- 채팅방 생성 및 입장, 퇴장
- 실시간 상태 업데이트 기능
- 게시글 작성 및 수정, 검사 기능

### 나중에 만들 기능

- 신고 기능

## 6. UI 구성

- 제목
- 설명
- 입력창
- 버튼
- 카드
- 목록
- 검색
- 필터

- 가장 먼저 보여야 하는 것: 게시글 및  채팅방의 카테고리 목록
- 가장 중요한 버튼: 채팅방 입장, 퇴장 버튼
- 추가 메모: 라이트 모드 / 화이트 모드

## 7. Acceptance Criteria

- 빈 문장은 출력하지 않는다.
- 카테고리에 맞는 채팅방 및 게시글이 있는지 확인하고 분류할 수 있다.
- 채팅방 입장, 퇴장이 자유롭게 가능하다.
- 실시간으로 앱 상태가 업데이트 된다.
- 관리자가 확인할 때 이외에 익명이 지켜진다.

## 8. 수정 기록

- 신고 기능을 나중에 만들기로 미루었다.
- 제재를 어떻게 해야할지 확립하지 못했다.

작품 기준 — 6회기에 팀이 직접 정합니다

어떻게 적나

  • MUST 3~5개 — 인원 수와 비슷하게 맞추면 분담이 바로 나옴
  • 기능마다 완료 조건을 한 줄 — "만들었다"가 아니라 "이렇게 하면 이렇게 된다"
  • 판정은 예 / 아니오 — "자연스럽게 · 예쁘게"는 조건이 아님
  • 작성자가 아닌 사람이 혼자 판정할 수 있어야 함

언제 쓰이나

  • 6회기 — PRD에 기록, 다른 팀 발표 리뷰로 검증
  • 7회기 — 한 바퀴 완결을 판정하는 기준
  • 9회기 — 이 표가 그대로 TEST.md가 됨
  • 10회기 — 상호 평가의 판정 질문

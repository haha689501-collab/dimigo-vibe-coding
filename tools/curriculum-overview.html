4 / 도구 · 규칙 · 안전

학생이 쓰는 도구

항목결정이유
Claude 데스크톱 앱✅ 설치Code 탭이 Claude Code. 10회기까지 이 앱 하나로 진행. 터미널 · VS Code는 쓰지 않음 (Node.js·Git 없는 노트북에서 직접 확인함)
Git✅ 설치세이브 기능. 커밋으로 버전 기록을 남기고 그때 그대로 되돌리기. 앱에 커밋 버튼은 없고 말로 시키면 Claude가 실행. 기록은 폴더 안 숨은 .git에 저장(인터넷 불필요)
Node.js · npm❌ 안 씀예전 설치 방식(npm)에만 필요. 2025년 10월 이후 불필요. React 같은 빌드형 프로젝트를 하지 않으므로 필요 없음
브랜치 · PR · 푸시❌ 몰라도 됨조마다 드라이버 한 명만 작업 → 충돌이 없음

작품 규칙 (첫 요청문에 항상)

  • index.html 파일 하나로 — 더블클릭하면 열리고 휴대폰에서도 그대로
  • 외부 라이브러리 · 인터넷 연결 없이
  • 휴대폰에서도 보기 좋게
  • 먼저 계획을 보여 주고, 승인하면 만들기
  • 고칠 때는 본 것 / 바라는 것을 나누고 "다른 부분은 바꾸지 마"

Git — 학생에게 하는 설명

  • Git = 세이브 기능 (프로그램)
  • 커밋 = 세이브 한 번 ("첫 화면 완성")
  • 되돌리기 = 세이브 불러오기 — 그때 그대로
  • "다시 만들어 줘"는 새로 만들기라 매번 다르게 나옴
  • 백업은 폴더째 압축 — 기록도 함께

⚠ API 키는 작품에 넣지 않는다

웹 작품의 코드는 F12로 누구나 볼 수 있습니다. 키를 넣으면 누구나 가져가 쓰고, 요금은 키 주인에게 청구됩니다.

대신: 대사 · 퀴즈 · 스토리를 Claude로 미리 잔뜩 만들어 파일에 넣기 ("AI는 만드는 데 쓰고, 작품 안에는 넣지 않는다")
